# Contributing to Tech Vriksh

Thanks for wanting to contribute! This is a student-driven project, so contributions of all sizes are welcome.

## Getting Started
1. Fork this repository
2. Clone your fork: `git clone https://github.com/<your-username>/Tech-Vriksh.git`
3. Install dependencies: `npm install`
4. Run the dev server: `npm run dev`

## Making Changes
1. Create a new branch: `git checkout -b feature/your-feature-name`
2. Make your changes
3. Run `npm run lint` and `npm run build` locally to make sure nothing breaks
4. Commit with a clear message describing what you changed
5. Push to your fork and open a Pull Request against `main`

## Guidelines
- Keep PRs focused on one change/feature at a time
- Follow the existing code style (TypeScript, Tailwind conventions already used in the repo)
- Describe what you changed and why in the PR description
- Be respectful and patient — this is a learning space
